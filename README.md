## 📖 Overview

Project Pinnacle is a production-grade DevOps and Cloud Engineering portfolio project designed to simulate how cloud infrastructure is built, secured, automated, monitored and maintained in a real engineering team.

This project focuses on engineering decisions, scalability, automation and cost optimization.

---

## 🎯 Objectives

- Build secure AWS infrastructure
- Automate deployments
- Implement Infrastructure as Code
- Deploy containerized applications
- Configure CI/CD pipelines
- Monitor workloads
- Centralize logs
- Practice disaster recovery
- Optimize cloud costs
